
# LinkedIn Clone 🚀

A full-stack LinkedIn-inspired social networking platform built using the MERN stack.

## ✨ Features

- User Authentication & Authorization
- Create and Manage Professional Profiles
- Create, Edit and Delete Posts
- Like and Comment on Posts
- Connect with Other Users
- Responsive User Interface
- Secure Backend APIs

## 🛠️ Tech Stack

- Frontend: React.js, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
- Tools: Git, GitHub, VS Code

## 📁 Project Structure

```text
linkedin-clone/
├── frontend/
├── backend/
├── .gitignore
└── README.md
```

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/samirkhan41/linkedin-clone.git
cd linkedin-clone
```

### 2. Install dependencies

```bash
cd frontend
npm install

cd ../backend
npm install
```

### 3. Configure Environment Variables

Create `.env` files in the frontend and backend directories as required.

### 4. Run the application

Start the backend:

```bash
cd backend
npm run dev
```

Start the frontend in another terminal:

```bash
cd frontend
npm run dev
```
